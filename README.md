# Ackis Recipe List (3.3.5a)

Profession recipe tracker for Wrath 3.3.5a. Scan your trades and see how to get missing recipes.

Upstream is [Ackis Recipe List v2.01](https://www.wowace.com/projects/arl) (Torhal / Ackis). This tree is the SingleWoW copy with local tooltip fixes.

## Install

Download the release zip and extract it into `Interface\AddOns` so you have:

`Interface\AddOns\AckisRecipeList\AckisRecipeList.toc`

Then `/reload`.

## Local changes (SingleWoW)

- Spell tooltip sits **beside** the acquire tooltip (below if it would go off-screen). TipTac restyles it but does not move it.
- Acquire tooltip lists trainers/vendors for **your faction + Neutral** only.
